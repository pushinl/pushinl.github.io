推理阶段 · 从评分头到 ATTENTION

评分头的分数，
到底怎样改变 attention？

先记住一件事：评分头给整块打 0～1 的分数；服务选中块以后，给块内每个 token贴上 1；attention 再把这个 1 加到该 token 的 QK 匹配分上，最后用 softmax 算权重。

块分数 p块→选块→token 标记 mi = 0 或 1→QK 匹配分 + mi→softmax 权重

容易混淆的地方：评分头算出的 0.9 不是“90% attention”，也不是直接把 0.9 加到 QK 上。当前默认加的是固定的 1，前提是这个块入选。

把动画写成完整公式

先看每行“产出什么”，再看下一行怎样使用它。这里的 qscore / kscore 与主模型 attention 的 Q / K 是两套不同的投影。

1得到块表示与当前表示

uj=1∣Bj∣∑i∈Bjhiu_j=\frac{1}{|B_j|}\sum_{i\in B_j}h_iuj​=∣Bj​∣1​i∈Bj​∑​hi​u⋆=hT−1u_\star=h_{T-1}u⋆​=hT−1​

h 是训练后模型算出的隐藏向量（2048 维）。一个约 256-token 的块取平均；前文最后位置的向量代表“当前要接着做什么”。

2评分头形成自己的 q、k

qscore=unit⁡(Wq LN(u⋆))q_{\mathrm{score}}=\operatorname{unit}(W_q\,\mathrm{LN}(u_\star))qscore​=unit(Wq​LN(u⋆​))kscore,j=unit⁡(Wk LN(uj))k_{\mathrm{score},j}=\operatorname{unit}(W_k\,\mathrm{LN}(u_j))kscore,j​=unit(Wk​LN(uj​))

两组独立的线性投影把 2048 维压到 128 维，unit 表示单位化。评分头用它们比较“当前需要”和“该块内容”。

3相似度、位置与 sigmoid

rj=4(qscore⋅kscore,j)+MLP⁡(posj)\begin{aligned}r_j&=4(q_{\mathrm{score}}\cdot k_{\mathrm{score},j})\\&\quad+\operatorname{MLP}(\mathrm{pos}_j)\end{aligned}rj​​=4(qscore​⋅kscore,j​)+MLP(posj​)​pj=σ(rj)=11+e−rjp_j=\sigma(r_j)=\frac{1}{1+e^{-r_j}}pj​=σ(rj​)=1+e−rj​1​

posⱼ 包含块中心、离前文末尾的距离、块长度三个特征；MLP 是 3→32→1 的位置修正网络。pⱼ 才是 0～1 的块评分。

4最重要的桥：分数变 0/1 标记

S=Top12⁡{j:pj≥0.5}S=\operatorname{Top12}\{j:p_j\ge 0.5\}S=Top12{j:pj​≥0.5}mi=1 ⁣[i∈⋃j∈SBj]m_i=\mathbf{1}\!\left[i\in\bigcup_{j\in S}B_j\right]mi​=1​i∈j∈S⋃​Bj​​

上式的 1[条件] 表示条件成立取 1，否则取 0。例子中 pB=0.9，所以 B₁、B₂ 的 m 都是 1。0.9 不作为 attention 的加分值；这一步已经把连续分数变成了位置清单。

5主模型算原始 QK，再加标记

st,i=Qt⋅Ki256s_{t,i}=\frac{Q_t\cdot K_i}{\sqrt{256}}st,i​=256​Qt​⋅Ki​​st,i′=st,i+λmi,λ=1s'_{t,i}=s_{t,i}+\lambda m_i,\quad\lambda=1st,i′​=st,i​+λmi​,λ=1

Q、K 来自主模型当前层，而不是评分头的 qscore、kscore。默认只在第 27、31、35、39 个 full attention 层执行这项加法。

6softmax 才得到 attention 权重

Zt=∑j≤test,j′Z_t=\sum_{j\le t}e^{s'_{t,j}}Zt​=j≤t∑​est,j′​at,i=est,i′Zta_{t,i}=\frac{e^{s'_{t,i}}}{Z_t}at,i​=Zt​est,i′​​ot=∑i≤tat,iVio_t=\sum_{i\le t}a_{t,i}V_iot​=i≤t∑​at,i​Vi​

Z 是所有可见位置的指数和；a 才是 attention 权重。最后用它汇总 V，影响后续计算与输出。

位置修正里的 posⱼ 到底是什么？

posj=(cj,dj,ℓj)\mathrm{pos}_j=(c_j,d_j,\ell_j)posj​=(cj​,dj​,ℓj​)cj=startj+endj2Tc_j=\frac{\mathrm{start}_j+\mathrm{end}_j}{2T}cj​=2Tstartj​+endj​​dj=log⁡(1+T−endj)log⁡(1+T)d_j=\frac{\log(1+T-\mathrm{end}_j)}{\log(1+T)}dj​=log(1+T)log(1+T−endj​)​ℓj=endj−startj256\ell_j=\frac{\mathrm{end}_j-\mathrm{start}_j}{256}ℓj​=256endj​−startj​​

c、d、ℓ 依次表示相对中心、离前文末尾的距离、相对块长度；它们进入小型位置网络，再与 128 维相似度相加。这个位置修正参与块评分，不是在 attention 里再次加分。

评分阶段使用完整的当前请求前文。评分后，服务用同一份前文进入生成阶段；一个请求内继续吐 token 不会重跑评分头。Agent 带着新工具结果发起下一轮请求时，才对更新后的前文重新评分。

为什么“原始 QK 很大，+1 仍有作用”？

看差值即可。下面是动画中 B 块的两个 token 从 1 加到 2 后，softmax 分母如何变化。

加权前：A 是 2、2；B 是 1、1

D0=e2+e2+e1+e1D_0=e^2+e^2+e^1+e^1D0​=e2+e2+e1+e1P0(B)=e1+e1D0=26.9%P_0(B)=\frac{e^1+e^1}{D_0}=26.9\%P0​(B)=D0​e1+e1​=26.9%

这里的 2 和 1 只是方便算的教学数字。

给 B 的两个 token 各加 1 后

D1=e2+e2+e2+e2D_1=e^2+e^2+e^2+e^2D1​=e2+e2+e2+e2P1(B)=e2+e2D1=50.0%P_1(B)=\frac{e^2+e^2}{D_1}=50.0\%P1​(B)=D1​e2+e2​=50.0%

把原始分改成 15、15、14、14，结果仍是 26.9%→50.0%，因为共同加上的 13 在 softmax 中会抵消。

边界：+1 会改变相对匹配分，但不保证最终任务效果一定更好；如果入选位置原本已几乎拿走全部 attention，总占比的提升也会因接近 100% 而变小。
