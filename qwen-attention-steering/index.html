01

对应最新部署的实际请求路径

一次外部请求，在网关内部拆成“评分”和“生成”两次模型请求。

客户端照常发送 issue、对话和工具结果。默认 head 模式下，网关完成以下步骤；评分阶段的文字输出不会成为最终回答的一部分。

评分头的输出是本次请求的“位置清单”。生成时，每一步的 Q/K 都在变，attention 权重也随之变化；固定的是清单，不是 attention 分布。

这是省略校验与日志后的代码示意。实际实现读取文件、验证哈希，并通过 custom_params 将控制信息送达 SGLang worker。

为什么名字叫 custom_logit_processor，真正干预却在 attention 内？

DiagnosticTransport.__call__ 验证控制参数、保存首步词表 logits，最后直接 return logits，不改变它们。它提供控制通路与诊断。真正加入历史位置偏置的是 RadixAttention.forward 的 hook 与 paged_attention_rows。

因此不能把这版实现理解成在最终词表上直接提高某些代码 token 的概率。

head / off / zero / random 的实际路径
head · 默认

运行评分，使用学到的选区；生成时加 λ，默认 1。

off

跳过评分，走普通生成；没有第二次评分请求的成本。

zero

仍运行评分并保留选区，但生成强度设为 0，attention hook 直接返回原生输出。

random

先评分确定预算，再从非选区、非特殊且非末位的候选历史 token 中随机采同样数量的位置；不是按随机块选择。

02

从隐藏状态到 token 选区

评分头先给块打分，再把选择展开到全部块内 token。

评分依赖学生对完整历史的表示，以及当前决策状态。它不是关键词匹配，不是另一个通过聊天指令工作的语言模型，也不是直接读取某一层的 attention 权重。

块的内容表示

历史块内 token 隐藏状态的均值 → 归一化与投影 → k_b

×
当前决策表示

前缀最后一个位置的隐藏状态 → 归一化与投影 → q

+
块的位置特征

相对位置、距末尾的距离、长度 → 小网络 g

p_b = sigmoid(4 × cos(q, k_b) + g(position_b))

内容匹配项衡量该块表示与当前决策表示的相关性，位置项提供顺序与长度信息。经过 sigmoid 得到连续分数 p_b；它用于选择，不当作最终 attention 概率。

① 排序并过门槛

按分数降序；保留 p_b ≥ 0.5 的前 12 块。同分时较小块编号优先。

② 展开为位置

取所选块的完整 token 区间并集；块内全部 token 进入选区。

③ 形成二值掩码

选区内 m_j = 1，其余为 0。其余 token 仍然保留在完整输入中。

本版是“块级评分、块级选择、token 位置加偏置”。不会在选中块内再次挑关键词；允许空选区，也不会为了凑满 12 块强选低分内容。

评分头的维度、分块边界与真实选择记录

隐藏维度为 2,048，内容投影到 128 维。评分头使用 LayerNorm、归一化投影的余弦相似度，以及 3 → 32 → 1 的位置网络；共 528,545 个参数，保持 FP32。位置特征为块中心相对位置、距末尾的对数距离、块长度 / 256。这里的 q / k 是评分头自己的投影，与 Transformer attention 的 Q / K 不同。

CP 分片按全局位置汇总块均值及最后位置，梯度可以回传到 LoRA。连续 token 分块只保证 UTF-8 可还原，不保证函数、句子或 traceback 不跨块。改变划分会同时影响训练标签、池化与推理，需要一致地重新设计。

2026-11-18 的合成 GPU 工具协议探针包含 64,329 个输入 token、252 块。默认规则选出 12 块、2,889 个 token。交互可查看实际分数与区间，不公开原始文本；这不是独立 SWE-bench 任务的重要性准确率。

03

从 attention 干预到输出变化

改变“怎样混合历史信息”，进而影响下一步预测。

必须区分两次归一化：attention 在历史位置之间分配权重；模型最后在词表 token 之间分配预测概率。Steering 直接改变前者，后者通过后续网络间接受到影响。

3.1 给选中历史位置的匹配分数加偏置

在某个被干预的 attention head 中，当前查询 q_t 与可见历史 key k_j 计算匹配分数。分数经过 softmax，变成对各个历史位置的 attention 权重。

原始匹配z_tj = q_t k_jᵀ / √d + M_tj

M 保留原有因果掩码；未来位置仍不可见。

增加偏置z′_tj = z_tj + λ m_j

选区 m_j = 1，额外加 λ；其余 m_j = 0，不额外加分。

重新归一化a′_tj = exp(z′_tj) / Σ_i exp(z′_ti)

所有可见位置一起归一化，得到新的混合比例。

本版默认 λ = 1。固定这一行原始 Q/K，选中位置相对未选位置的未归一化权重乘以 e¹ ≈ 2.718；最终 attention 概率仍取决于全行的分母。选中的所有 token 加同样的 λ，不按评分头分数再区分强弱。

在这版代码中，上述公式怎样真正执行？

RadixAttention.forward 先运行原生 attention，以完成正常计算与 KV 写入。随后取得本请求逻辑位置对应的物理 KV 槽，只重算目标查询行，再用修正结果替换该行原输出。其他查询行保留原生结果。

# core.py / runtime.py：省略分块与数值稳定细节
logits = q @ k.transpose(-1, -2) * scaling
logits += strength * marked.float()   # 选中的历史位置 +λ
weights = softmax(logits)
changed = weights @ v
result[query_rows] = changed         # 替换 attention 输出行

实际实现按 2,048 个 key 一组读取 KV，用在线 softmax 的最大值、分母和加权分子累计，避免一次展开整张历史 attention 矩阵；累计精度为 FP32。

runtime.py:196–206 · core.py:171–190

3.2 用新权重对 V 求加权和

每个历史位置还有 value 向量 v_j，承载该位置的信息表示。Attention 的输出是这些向量的加权汇总；改变权重，就改变哪些位置的信息以多大比重进入当前查询的表示。

u′_t = Σ_j a′_tj v_j

3.3 汇总结果经过后续网络，影响词表预测

多头结果经过输出投影，与残差路径等信息共同进入后续层。最终隐藏状态被语言模型输出层映射到整个词表的分数，再经过 softmax 得到下一个 token 的概率。

→
Σ a′V当前信息汇总改变 attention 输出
→
h_final后续层与残差计算形成最终隐藏状态
→
W_vocab h_final词表分数 → 概率预测下一个 token

当生成的是工具调用时，这些 token 会组成工具名、路径、命令或参数；当生成的是代码时，它们会组成补丁内容。变化后的动作又会获得不同的工具观察，影响后面的 Agent 轨迹。一次局部 attention 干预，可能通过多轮交互影响最终补丁。

这里没有固定的“attention 增量 → 成功率增量”公式

后续网络、多头信息、残差路径和采样共同决定输出。单个历史位置权重增大，并不保证某个正确代码 token 的概率增大，也不保证任务被解决。真实输出方向需要测量，真实效果需要独立任务对照。

3.4 本版具体在哪些层、哪些查询上生效

固定在第 27 / 31 / 35 / 39 层的所有 attention heads 上，为最后一个前缀查询和之后的逐 token 生成查询加入偏置。较早的历史查询行不接受本次修正；被增强的 key 位置来自评分阶段选中的历史块。

40 层，层号从 0 开始。绿色边框是本版的固定干预层；点击查看。

每四层中有一层 full attention，最后四个 full attention 层被选为干预层。

Full attention 显式计算面向历史位置的 QK 分数，适合逐位置加偏置。Linear attention（Gated DeltaNet）通过递归状态汇总历史，不能直接套用同一套 softmax 位置偏置。后四个 full attention 层是固定原型选择，目前没有独立效果证据证明它们最优。

计算边界、偏置不变性与运行实现

固定 Q/K 后，选区原本的 attention 合计为 r，新合计为 r′ = e^λ r / (1 − r + e^λ r)。λ = 0、空选区，以及同一查询行所有可见 key 都加同一常数时，分布不变。实际 decode 中，选中全部历史块不等于选中包含新生成 token 在内的全部可见 key。

当前运行路径先执行原生 attention，再从实际 KV 槽重算需要修正的查询行，使用 FP32 softmax，写回修正后的输出。参数权重不会在单次请求中因此更新；较早层的干预则可能影响后续层的 Q/K/V。上述局部公式比较的是同一行、相同原始 Q/K 下的直接偏置效果。

历史验收的范围与限制

8 个独立副本并行约 64k 输入，两轮工具往返每路合计约 62–69 秒。包含 tool_use ID、名称、参数、匹配 tool_result 和正常结束的 SSE。第一轮强制选择 Bash，第二轮 auto；初始自动工具选择探针曾直接回答而未调用工具。这不证明自主工具选择能力提升。

配置上下文上限 262,144，不等于该长度已完成压力验收。约 64k 记录属于流程验收，不是完整 Agent benchmark 或对照加速结果。历史记录不说明当前服务实时状态。

A1

决策数据与教师标注

每个训练样本，固定在 Agent 的一个决策时刻。

样本包含当时的完整可见历史；动作目标来自轨迹中随后记录的动作，重要性标签来自教师对当前历史的选择。两种监督有不同来源。

Issue / 仓库环境→检索、读代码→复现、观察错误→修改、运行测试↺继续决策
输入 xₜ：截至此刻的可见历史

系统与工具说明、issue、已执行的工具调用和结果、模型此前的回复。保留原有顺序、关联和完整 token。

动作目标 aₜ：轨迹中的下一步

例如检索源码、执行复现命令或修改文件。只有格式有效的动作才用于动作模仿；格式有效不代表动作正确。

重要性标签 yₜ：教师的块级选择

按约 256 token 切连续块，让教师只基于当前可见历史选至多 12 块，也允许不选。

监督边界

教师可以看到已执行且已返回的复现结果、报错和反证；看不到下一步动作、未来工具结果、标准补丁或评测器的隐藏答案。学生的重要性特征也不使用未来动作。

教师的选择准则包括：当前仍有效的用户约束、能区分候选解释的代码和工具观察、推翻旧假设的反证，以及尚未解决的状态。它输出块 ID，再转换成 0 / 1 标签；不是让教师替学生生成修复方案。

辅助例子某配置加载器忽略了显式 timeout=0，哪些历史可能更重要？

这是合成的仓库修复场景，用于说明数据结构，不是真实 SWE-bench 题目或本次训练原文。

Issue 约束

timeout=0 表示禁用超时，应保留该值。

已读源码

timeout = cfg.get("timeout") or 30

已返回的复现结果

显式传入 0，实际变成 30；失败发生在配置解析路径。

其他历史

依赖安装成功、重复目录输出、已被证据否定的网络猜测。

教师可以把 issue、相关源码和复现结果标为重要。下一步动作可能是继续检查调用方或添加回归测试；具体动作由记录的轨迹提供，不是由重要性标签直接规定。

A2

联合训练的目标与梯度

既学习产生下一步动作，也学习判断历史的重要性。

在已有学生模型上增加可训练的重要性头。它从初始化的参数开始，通过预测分数、计算监督误差、反向传播和参数更新逐步学会打分。

完整前缀 → 学生的因果隐藏状态
语言模型输出层预测记录中的有效动作 token动作损失 L_action
重要性评分头预测每个历史块的分数 p重要性损失 L_salience
两项误差回传 → 更新 LoRA 与评分头；底座原始参数冻结
L = L_action + 0.1 × L_salience

动作 CE：学习下一步怎样生成

对记录中格式有效的动作进行 token 级预测，提高动作目标在给定历史下的概率。目标是动作模仿，不是直接最大化 SWE-bench 的 resolved 指标。

重要性 BCE：学习哪些块应选中

教师选中的块标签为 1，其余为 0。比较分数与标签的差异；正负块分别求平均、各占一半，避免大量未选中块淹没少量重要块。

重要性损失不只训练评分头：隐藏状态由带 LoRA 的学生计算产生，误差也沿这个路径传回 LoRA。底座参数冻结不等于表示完全固定。训练结束后合并 LoRA、导出 FP8 推理权重，同时保存与该权重匹配的 FP32 评分头。

训练监督的是动作预测与块级重要性，并未直接拟合每一层的 attention 矩阵。在线增加 attention 偏置，是训练完成后单独接入的计算步骤。

分数越接近 1，这块的分类损失越小。

数值是教学设定，不是训练日志或单步收敛承诺。
本次训练配置与损失细节

标签为 1 时，单块 BCE 为 −log(p)；标签为 0 时为 −log(1−p)。同时有正负块时，平衡 BCE 为正块均值与负块均值各占一半；全负标签也可训练。无有效动作目标的样本不参与动作模仿。

训练底座是指定 FP8 checkpoint 的 BF16 反量化版本，底座冻结。LoRA rank 32、alpha 64，覆盖独立 Q/K/V 与共享、路由专家；评分头保持 FP32。LoRA 参数 143,851,520，加评分头 528,545，共 144,380,065 个逻辑可训练参数。

16 × 910B，CP8 / DP2 / EP8，global batch 32（尾批 30），峰值学习率 10⁻⁵。从 checkpoint-48 保留优化器、随机数和数据位置，累计至 665 步、1 epoch，全部 21,278 样本各曝光一次。动作目标和 padding 不进入重要性池化，因果隐藏状态也不读取未来动作。

把完整路径串起来

训练阶段：完整 Agent 历史 → 教师块标签与动作监督 → 联合训练学生和评分头。

推理阶段：当前历史 → 评分 → token 掩码 → attention logits 偏置 → V 加权汇总变化 → 后续网络与输出分布 → 新动作和新观察。

评测阶段：在独立任务、相同 Agent 配置下比较，判断最终补丁收益与代价。
